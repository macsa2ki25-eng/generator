# FIND ME — 発電機修理アプリ

文化祭の出し物「FIND ME」（Dead by Daylight風 脱出ゲーム）用の発電機アプリです。

- タブレットの画面を **長押ししている間だけ** 発電機の修理ゲージが進む
- 修理中は **修理音**（ガチャガチャ…）が鳴る → 殺人鬼に気づかれる！
- ときどき **スキルチェック**（タイミングよくタップ）が出る。失敗すると爆発してゲージが減る
- 他の2台の発電機の修理状況も画面に表示される
- 3台すべて復旧すると **明かりがつき、ゲート開放！**
- 制限時間を過ぎると **TIME OVER**

インターネット接続は一切不要です（教室のWi-Fiの中だけで動きます）。

---

## 必要なもの

| もの | 用途 |
|---|---|
| PC 1台（Windows / Mac どちらでも） | サーバー役。教室の隅に置いておく |
| [Node.js](https://nodejs.org/ja)（無料） | PCに1回インストールするだけ |
| タブレット 3台 | 発電機として教室に設置 |
| （あれば）スタッフ用のスマホやPC | モニター画面・スタート操作用 |

PCとタブレットは **同じWi-Fi** につないでください。

## 準備：この一式（フォルダ）を用意する

まず、このアプリのファイル一式を **PCのデスクトップ** など分かりやすい場所に置きます。

- **GitHubからダウンロードした場合**：緑色の「Code」→「Download ZIP」で保存 → できた ZIP ファイルを**右クリック→「すべて展開」（Macはダブルクリック）で解凍**します。
- 解凍してできた **`generator` というフォルダ**（中に `server.js` や `README.md`、`はじめに-Windows.bat` などが入っているフォルダ）が、これから使う「このフォルダ」です。

> 💡 「このフォルダの中で」と書いてあるのは、いつもこの `generator` フォルダのことです。

## 動かし方（3ステップ）

### ① サーバーを起動する

**いちばんかんたんな方法（ダブルクリックするだけ）**

`generator` フォルダの中にある起動ファイルを**ダブルクリック**します。

- Windows → **`はじめに-Windows.bat`**
- Mac → **`はじめに-Mac.command`**

黒い画面が開いて、下のような表示が出れば起動成功です。

> ⚠ Windowsで「WindowsによってPCが保護されました」と出たら、「詳細情報」→「実行」を押してください。
> Macで「開けません」と出たら、そのファイルを**右クリック→「開く」**を選ぶと実行できます（最初の1回だけ）。

<details>
<summary><b>ダブルクリックでうまくいかない時：ターミナルから起動する方法</b></summary>

「このフォルダの中で」ターミナルを開くには：

- **Windows**：`generator` フォルダをエクスプローラーで開く → 上のアドレス欄（フォルダの場所が出ている細長い部分）をクリックして `cmd` と入力し Enter。そのフォルダの場所でコマンドプロンプトが開きます。
- **Mac**：「ターミナル」アプリを開く → `cd ` と入力（cd のあとに半角スペース）→ `generator` フォルダを**ターミナルの画面にドラッグ＆ドロップ** → Enter。これでそのフォルダに移動できます。

移動できたら、次を入力して Enter：

```
node server.js
```
</details>

どちらの方法でも、こんな表示が出ます:

```
==================================================
   FIND ME  発電機サーバー 起動！
==================================================

 タブレットのブラウザで、下のどれかのURLを開いてください:

   http://192.168.1.23:3000
```

### ② タブレットで開く

タブレット3台それぞれのブラウザ（Safari / Chrome）で、表示されたURL
`http://192.168.1.23:3000`（数字はPCによって違います）を開きます。

「発電機 1」「発電機 2」「発電機 3」を1台ずつ選びます。

### ③ スタッフ画面からスタート

スタッフ用のスマホやPCのブラウザで同じURLを開き、
「スタッフ用（モニター・設定）」を選んで **▶ ゲームスタート** を押します。

これだけです！

## 設定（スタッフ画面の下のほう）

| 設定 | 意味 | おすすめ |
|---|---|---|
| 🔧 修理にかかる時間 | 1台を押しっぱなしで何秒で終わるか | 90秒 |
| ⏰ 制限時間 | タイムオーバーまでの時間 | 5分 |
| 🎯 スキルチェック | タイミングタップのミニゲームの難しさ | かんたん |
| 💥 失敗のペナルティ | スキルチェック失敗で減るゲージ | 8% |
| 📉 さわっていない間に下がる | オンにすると難易度アップ | オフ |

> スキルチェックは **やさしめ** に調整済みです（ゾーンが広く・針もゆっくり・出現も控えめ）。
> 光ったゾーンで画面をタップすれば成功（GREATで＋4%、OKで＋2%のボーナス）。
> **指を離してタップし直してもOK**（二本目の指でなくても大丈夫）。難しすぎる時は「なし」にもできます。

変えたら **💾 保存** を押すと、全タブレットにすぐ反映されます。
設定はファイル（`settings.json`）に残るので、サーバーを再起動しても消えません。

## ずっと放置して展示するための設定（勝手に閉じない・消えないように）

生徒しかいない教室で長時間放置するので、事故で閉じたりスリープしても大丈夫なように、
アプリ側でも対策を入れてあります。さらに端末の設定を合わせると、ほぼ無敵になります。

**アプリが自動でやること**
- **画面が消えないようにする**（Wake Lock。復帰時にも自動でかけ直します）
- **もし閉じても復帰できる**：同じURLをもう一度開けば、サーバーが進行状況を覚えているので
  その場から再開します。トップページには「▶ 発電機N を再開」ボタンも出ます。
- PCブラウザで **×や再読み込みを押すと確認**が出ます（誤操作の保険）

**端末側でやっておくと安心（強くおすすめ）**

1. **自動ロック（スリープ）を「なし」に**
   - iPad：設定 → 画面表示と明るさ → 自動ロック → **なし**
   - Android：設定 → ディスプレイ → 画面消灯 → 一番長く／なし
2. **ホーム画面に追加して全画面アプリにする**（×ボタンやアドレスバーが消えます）
   - iPad(Safari)：共有ボタン → **「ホーム画面に追加」** → 追加されたアイコンから起動
   - Android(Chrome)：メニュー → **「アプリをインストール」／「ホーム画面に追加」**
3. **画面を固定して勝手に閉じられないようにする**（いちばん確実）
   - iPad：設定 → アクセシビリティ → **アクセスガイド** をオン。アプリ起動後にホームボタン/上ボタンを3回押すと、その画面から出られなくなります（解除も同じ操作＋パスコード）
   - Android：設定 → セキュリティ → **アプリの固定（画面のピン留め）** をオン

> この3つ（自動ロックなし＋ホーム画面アプリ＋画面固定）をやっておけば、
> 放置中に生徒が触っても、閉じたりホームに戻ったりできなくなります。

## 「サーバーのPCだけ表示され、他の端末は“接続中”のまま」の時

いちばん多いのは **サーバーを動かしているPCのファイアウォールが、他の端末からの接続をブロック** しているケースです。
自分自身（PC上のブラウザ）からは見えるのに、タブレットからは真っ白／読み込み中のまま、という時はほぼこれです。

まず切り分けます:

1. **アドレスの確認**：つながらない端末では、黒い画面に出た **`http://192.168.○○.○○:3000`（数字のアドレス）** を入力していますか？
   `localhost:3000` は「その端末自身」を指すので必ず失敗します。`https://` ではなく **`http://`** です。
2. **ファイアウォールを一時オフにして再確認**（Windows）：
   設定 →「プライバシーとセキュリティ」→「Windows セキュリティ」→「ファイアウォールとネットワーク保護」→
   **今つないでいるネットワーク**（アクティブと表示）を開いて、ファイアウォールを**一時的にオフ** → タブレットで再アクセス。

**これでつながったら、原因はファイアウォールです。**
オフのままにはせず、下のどちらかで「ポート3000だけ」を許可してから、ファイアウォールをオンに戻してください。

- **かんたん**：同梱の **`ファイアウォール許可-Windows.bat`** をダブルクリック
  → 「はい」（管理者の許可）を押すだけで、ポート3000への接続を許可します。
- **手動**：「Windows Defender ファイアウォール」→「アプリまたは機能を許可」→ 一覧の **Node.js** に、
  **プライベート／パブリック 両方**のチェックを入れる（テザリングは「パブリック」扱いのことが多いので両方が大事）。

> 💡 最初に `node server.js` を実行したとき「Windowsによってブロックされました／アクセスを許可しますか」と出ていたら、
> そこで **「アクセスを許可する」** を押せば同じ設定になります（消してしまっていたら上のbatを使ってください）。

## 学校のWi-Fiでつながらないとき

学校のWi-Fiはセキュリティ設定で「端末どうしの通信（AP分離）」が禁止されていることがあります。
タブレットからURLを開いても画面が出ない・「接続できません」と出る場合はこれが原因です。

> ⚠ **スマホのテザリングでもつながらない場合**、ファイアウォール（上の節）を先に確認してください。
> それでもダメなら、テザリング自体が端末どうしの通信を遮断している可能性があります。
> その場合は **iPhoneの「インターネット共有」に変えてみる**（Androidより通しやすいことが多い）か、
> **家庭用/モバイルWi-Fiルーター**（インターネット契約不要・中継役）を使ってください。

**対策（どれか1つでOK）:**

1. **スマホのテザリング（一番かんたん）**
   スマホの「インターネット共有 / テザリング」をオンにして、PCとタブレット3台をそのWi-Fiにつなぐ。
   ※通信はぜんぶ教室内で完結するので、スマホのギガはほぼ減りません。
2. **モバイルWi-Fiルーター / 家庭用ルーター** を教室に持ち込む（インターネット契約は不要。ただの中継役です）
3. 学校のICT担当の先生に「AP分離を外せるか」相談する

### それでもダメなとき: ひとりモード（緊急用）

各タブレットで「接続できません」バナーの **「ひとりモードで動かす」** を押すと、
サーバー無しでそのタブレット単体で動きます（他の発電機の状況は表示されません）。
画面のスタートボタンで開始します。設定は、一度スタッフ画面で保存した内容が使われます。

## よくある質問

**Q. インターネットに情報が送られる？**
A. 送られません。教室内のPCとタブレットの間だけで通信します。外部のサーバーやCDNは一切使っていません。

**Q. `node server.js` で「command not found」と出る**
A. Node.jsがインストールされていません。https://nodejs.org/ja からLTS版を入れてください。`npm install` は不要です（追加パッケージを使っていないため）。

**Q. ポート3000が使えないと言われた**
A. `PORT=3001 node server.js`（Windowsは `set PORT=3001 && node server.js`）で別の番号にできます。URLも `:3001` に変わります。

**Q. 音が出ない**
A. タブレットの消音（マナー）スイッチを解除してください。ブラウザの仕様で、一度画面をタッチするまで音は鳴りません。画面下の「🔇 タップで音を出す」を押すと有効になります。

**Q. 効果音（修理中・修理完了・爆発）を別の音に変えたい**
A. 音声ファイルを同じ名前で置き換えるだけです。
- 修理中（押している間ループ）：`public/sound/repair.mp3`
- 修理完了（1回だけ再生）：`public/sound/completed.mp3`
- 爆発＝スキルチェック失敗（1回だけ再生）：`public/sound/explosion.mp3`

これらは「素の音のまま」（合成効果音のような歪ませて大きくする処理は通さず）再生します。音量は `public/js/audio.js` の `REPAIR_GAIN`／`COMPLETE_GAIN`（今 0.9）と `EXPLOSION_GAIN`（今 2.5）で調整できます。数値を上げるほど大きくなりますが、上げすぎると音割れします（爆発ファイルは元が小さめなので 2.5 まで上げても割れません。差し替えるファイルによって適正値は変わります）。ファイルが読み込めない場合は自動で合成音（元の音）に切り替わります。
