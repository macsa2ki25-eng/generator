# 日本株スイングトレード・アドバイスアプリ 構想書

自分専用の、日本株スイングトレード支援ツール。JPX日経400を監視対象とし、
テクニカル指標に基づく機械的なエントリー/イグジット判断と、
iSPEED風のチャート閲覧・スクリーニングを提供する。

---

## 1. 目的とゴール

- **機械的なトレード**: 感情を排し、明文化されたルールでエントリー・イグジットを判断する
- **毎日の運用イメージ**: 引け後にアプリを開く → 「今日のエントリー候補」を確認 →
  翌日の注文(エントリー価格・損切り・目標)が具体的な数字で提示されている →
  保有銘柄には「継続 / 利確 / 損切り」の判定が出ている
- **閲覧機能**: 銘柄ごとのメインページで、日中足・日足・週足・月足のローソク足、
  出来高、移動平均線、価格帯別出来高を一画面で確認できる
- **検証可能性**: すべてのルールはバックテストで過去成績を確認してから採用する

## 2. 前提と正直な注意点

### 勝率について
- 「必ず勝てるルール」は存在しない。テクニカル戦略の優位性は一般に小さく、
  相場環境(上昇トレンド/レンジ/下落)によって成績が大きく変わる
- 評価は勝率単体ではなく **期待値**(勝率 × 平均利益 − 敗率 × 平均損失)と
  **最大ドローダウン** で行う。勝率40%でも損小利大なら勝てるし、勝率70%でも
  コツコツドカンなら負ける
- 過剰最適化(カーブフィッティング)を避けるため、ルールはシンプルに保ち、
  検証期間を「最適化用」と「確認用(アウトオブサンプル)」に分ける
- 手数料・スリッページを織り込んで検証する
- **最重要なのは資金管理**: 1トレードの損失を資金の1〜2%に固定する
  ポジションサイズ計算をアプリに組み込む

### データについて
- 無料データにはそれぞれ制約がある(後述)。特に日中足(分足)のリアルタイム性は
  無料では限界があるため、**シグナル判定は日足確定ベース(引け後バッチ)を基本**とし、
  日中足はチャート閲覧用と位置づける。スイングトレードなら日足ベース判断で十分機能する
- 価格帯別出来高は、ティックデータなしでは厳密には計算できない。
  日足/分足の四本値+出来高から近似計算する(実用上は十分)

### 法律面
- 自分専用ツールなら投資助言業の登録は不要。ただし第三者に配布・助言提供すると
  金融商品取引法に抵触しうるため、**自分用に留める**

## 3. データソース戦略

| ソース | 費用 | 取得できるもの | 制約 |
|---|---|---|---|
| yfinance (Yahoo Finance) | 無料 | 日足・週足・月足(長期)、分足(5分/15分は直近約60日、1分は直近約7日)、出来高 | 約15〜20分遅延。非公式APIのため仕様変更リスクあり |
| J-Quants API (JPX公式) | 無料プラン / ライト約1,650円/月 | 日足、財務、コーポレートアクション等 | 無料プランは12週遅延で実運用不可。ライトなら当日日足が夜に取得可 |
| 証券会社API (kabuステーション、立花e支店等) | 口座があれば無料 | リアルタイム株価 | 実装難度が上がる。将来の拡張枠 |

**方針**: Phase 1〜4 は yfinance で構築し、データ取得層を抽象化しておく。
安定性が欲しくなったら J-Quants ライトプランへ差し替え(日足系はそのまま移行可能)。
リアルタイム日中足が必要になったら証券会社APIを検討。

## 4. 対象ユニバース

- **JPX日経400 構成銘柄**(JPX/日経の公表リストから取得、年次入替に追従)
- 400銘柄 × 日次バッチなら計算量・API負荷ともに問題ない規模
- 銘柄リストはCSVで持ち、手動での追加・除外も可能にする(お気に入り銘柄など)

## 5. 機能一覧(画面構成)

### 5.1 今日のエントリー候補(トップページ)
- 夜間バッチが生成したシグナル一覧。銘柄ごとに:
  - シグナル種別(押し目買い / ブレイクアウト等)とスコア
  - **エントリー価格**(翌日寄り成行 or 逆指値の値)
  - **損切り価格**(初期ストップ)
  - **利益目標**(リスクリワード比つき)
  - **推奨株数**(資金と1トレード許容リスクから自動計算)

### 5.2 銘柄メインページ(iSPEED風)
- ローソク足チャート: 日中足(5分/15分)・日足・週足・月足をタブ切替
- 出来高バー(価格チャート下部)
- 移動平均線: 日足 5/25/75日、週足 13/26/52週(設定変更可)
- **価格帯別出来高**: チャート右側に横向きヒストグラム表示
- シグナル発生地点のマーカー、エントリー/ストップ/ターゲットの水平線
- 基本情報: 現在値、前日比、52週高安、平均出来高 等

### 5.3 スクリーニング
- 条件フィルタ: トレンド状態(パーフェクトオーダー等)、MAとの乖離率、
  出来高急増、新高値接近、シグナル種別、等
- 結果はソート可能なテーブル → クリックで銘柄ページへ

### 5.4 ポジション管理
- 保有銘柄を登録(取得単価・株数)
- 毎日のバッチで各ポジションに判定を出す: **「継続」「利確」「損切り」「トレーリング更新」**
- 現在の含み損益、ストップまでの距離、保有日数を表示

### 5.5 バックテスト
- 戦略・期間・ユニバースを指定して過去シミュレーション
- 出力: 期待値、勝率、プロフィットファクター、最大ドローダウン、
  トレード一覧、資産曲線グラフ

## 6. シグナル/戦略エンジン設計(初期セット)

以下は「よく知られ、原理が説明できる」定番手法をベースにした初期候補。
**バックテストで成績を確認し、ダメなものは捨てる**(これが前提)。

### 共通トレンドフィルタ(買いの土俵に乗せる条件)
- 週足: 26週MAが上向き、かつ株価がその上
- 日足: 75日MA上向き(長期上昇トレンド内でのみ買う)

### セットアップA: 押し目買い
- 上昇トレンド中、株価が25日MA近辺まで押す
- 反発の陽線(前日高値超え)+出来高を伴う
- エントリー: シグナル日高値超えの逆指値
- 初期ストップ: 直近押し安値の少し下 or 2×ATR(14)下

### セットアップB: 高値ブレイクアウト
- 直近60日高値を終値で更新
- 出来高が20日平均の1.5倍以上
- 価格帯別出来高で上値に「節」(しこり)が薄いことを加点
- エントリー: 翌日寄り成行
- 初期ストップ: ブレイクしたレンジの内側 or 2×ATR下

### イグジットルール(全セットアップ共通の枠組み)
1. **損切り**: 初期ストップに到達(逆指値を置く前提の価格を提示)
2. **利益目標**: リスクの2倍(2R) or 上値の価格帯別出来高の節 — 近い方
3. **トレーリング**: 利が乗ったら終値ベースで10日MA(短期)/25日MA(中期)割れで手仕舞い
4. **時間切れ**: エントリー後N日(例:10営業日)経っても進展がなければ撤退

### 資金管理(サイズ計算)
- 設定: 総資金、1トレード許容リスク(資金の1〜2%)
- 推奨株数 = 許容リスク金額 ÷ (エントリー価格 − ストップ価格)、単元株に丸め

## 7. 技術構成

```
swing-trade/
├── backend/            # Python (FastAPI)
│   ├── data/           # データ取得層(yfinance実装、将来J-Quants差替可能に抽象化)
│   ├── indicators/     # MA, ATR, 出来高分析, 価格帯別出来高(近似計算)
│   ├── signals/        # セットアップ判定・スコアリング
│   ├── backtest/       # 日足イベントループ型バックテスター
│   ├── portfolio/      # ポジション管理・イグジット判定
│   └── api/            # REST API
├── frontend/           # 静的HTML/JS(ビルド不要)
│   └── lightweight-charts(TradingView製OSS)でローソク足描画
│       価格帯別出来高は同ライブラリのプラグイン機構で描画
├── db: SQLite          # 株価キャッシュ・シグナル履歴・ポジション
└── 起動: ダブルクリック用の start.command / start.bat(既存プロジェクトと同様)
```

- Python + pandas でテクニカル計算、SQLiteにキャッシュ(毎回全取得しない)
- フロントはビルド工程なしの静的ファイル+CDNではなくローカル同梱のJSライブラリ
- バッチはアプリ起動時 or 画面の「データ更新」ボタンで実行(引け後に1回)

## 8. 開発フェーズ

| Phase | 内容 | ゴール |
|---|---|---|
| 1 | データ基盤+銘柄ページ | JPX400の日足/週足/月足/分足チャートがMA・出来高・価格帯別出来高つきで見られる |
| 2 | スクリーニング+シグナル | エントリー候補リストが毎日出る(価格・ストップ・目標つき) |
| 3 | バックテスト | 戦略の過去成績を数字で確認し、ルールを取捨選択 |
| 4 | ポジション管理 | 保有銘柄のイグジット判定が毎日出る |
| 5 | 拡張 | J-Quants移行、通知(メール/Discord)、日中足シグナル 等 |

Phase 3(バックテスト)を経てからシグナルを本採用する。
「数字で確認していないルールは信じない」を原則とする。
