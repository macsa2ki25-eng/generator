# スイングトレード分析アプリ

日本株スイングトレードの自分専用分析ツール。
構想・ロードマップは [CONCEPT.md](CONCEPT.md) を参照。

**現在: Phase 1(チャート閲覧・スクリーニング基盤)**
- JPX主要銘柄(約130、フルのJPX400へ更新可)の監視
- 日中足(5分/15分)・日足・週足・月足のローソク足チャート
- 移動平均線(赤=5日 / 緑=20日 / 青=60日。週足・月足は各時間軸の定番期間)
- 出来高・価格帯別出来高(チャート右側のヒストグラム)
- 簡易スクリーニング(パーフェクトオーダー / 60日線上 / 52週高値圏 / 出来高急増)

## 起動方法

**Mac**: `はじめに-Mac.command` をダブルクリック
**Windows**: `はじめに-Windows.bat` をダブルクリック

初回はライブラリの自動インストールに数分かかります。
起動するとブラウザで `http://127.0.0.1:8765` が開きます。

初回はアプリ内の「データ更新」で全銘柄の日足を取得します(1〜2分)。
株価データは Yahoo Finance(yfinance)から取得し、SQLiteにキャッシュされます。

## 使い方のメモ

- 左のリストで銘柄を選択(↑↓キーでも移動可)。検索欄に4桁コード+Enterでリスト外の銘柄も表示可能
- チャート上部のタブで時間軸を切替。日中足は約15〜20分遅延・直近約60日分
- チャート右側の横棒が価格帯別出来高(金色=最も出来高が厚い価格帯)。四本値からの近似計算
- 「データ更新」は引け後(夕方以降)に1回押せば十分

## 銘柄リストの更新(任意)

フルのJPX日経400構成銘柄に更新する場合:

```bash
python scripts/update_universe.py
```

(公式の公表CSVから取得。URLが変わって失敗する場合はスクリプト内のURLを修正)

## デモモード

ネット接続なしでUIを確認するための合成データモード。
実データと混同しないよう画面上部に赤いバナーが表示されます。

```bash
SWT_PROVIDER=demo python -m backend.main        # Mac
set SWT_PROVIDER=demo && python -m backend.main # Windows
```
